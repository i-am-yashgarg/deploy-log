Nextup Logbook — Demo Website
⚠️ Important: This repository/page is only a presentation and demonstration website for the Nextup Logbook application. It is NOT the actual application.

🚀 About
Nextup Logbook Demo is a responsive, interactive landing page created to demonstrate the concept, interface, workflow, and capabilities of the real Nextup Logbook application.

The demo is designed for:
- Project presentations
- Product demonstrations
- College/project showcases
- Portfolio websites
- Client demonstrations
- Explaining the application's workflow without connecting to production data
It provides a presentation-style experience with animated sections, an interactive product preview, a product tour, workflow explanation, role-based access explanation, and technology overview.
⚠️ Demo vs. Real Application
This project should not be confused with the actual Nextup Logbook application.
This repository contains
- A presentation/marketing webpage
- UI animations
- Interactive mock screens
- Product tour
- Feature explanations
- Workflow visualization
- Technology overview
- Links to the real application repository
This repository does NOT contain
- The production application's complete backend
- Production Supabase database
- Real user authentication
- Real robot records
- Real deployment records
- Real maintenance records
- Production operational data
- The complete source code of the actual application
The interactive screens shown on this website are demonstration/mock data intended to explain how the real application works.

▶️ Run Locally
No build system is required.

Simply open:
index.html
in a modern web browser.

Or use a local server:
python3 -m http.server 8000
Then open:
http://localhost:8000
🌐 Deploy on Netlify
This demo is suitable for static hosting.
Option 1 — Netlify Drag & Drop
1. Put index.html and README.md in a folder.
2. Open Netlify.
3. Drag the folder into the deployment area.
4. Netlify will publish the demo website.
Option 2 — GitHub + Netlify
Push the project to GitHub and connect the repository to Netlify.

Because this is a static HTML website, no build command is required.
